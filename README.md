# FlClash iOS v0.9.1

This private project ports upstream chen08209/FlClash v0.9.1 to iOS while preserving the upstream UI.

The source archive contains the complete project, a patch against the original tag, licensing notices, native Network Extension integration, build scripts, and validation notes in README_IOS.md.

**Status:** iOS build and real-device networking validation are pending. An unsigned IPA still requires valid Apple signing and provisioning.

Upstream commit: `8d4f9744948751f1273fe871e1d05276fac09b0e`.

Use the Actions workflow **Build FlClash iOS v0.9.1** to build and download the IPA artifact.
